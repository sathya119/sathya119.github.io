It is a new language to make on-shell properties manifest.

Consider on-shell momentum $$p^\mu$$. Define

$$p^{\dot\alpha\alpha}=p_\mu(\bar\sigma^\mu)^{\dot\alpha\alpha}=\begin{pmatrix}p^0+p^3&p^1-ip^2\\p^1+ip^2&p^0-p^3\end{pmatrix}$$

where $$\bar\sigma^\mu=(\mathbb{1}_z,-\vec \sigma)$$

with $$\mathbb{1}_z=\begin{pmatrix}1&0\\0&1\end{pmatrix}$$ and [[Pauli Matrices]] as always.

Locally, the Lorentz Group can be written as $$SU(2)\times SU(2)$$ and $$\alpha,\;\dot\alpha$$ are the indices for the fundamental representation of each $$SU(2)$$.

Then, $$p^2=p_\mu p^\mu=det(p^{\dot\alpha\alpha})=(p^0)^2-\sum_i (p^i)^2=m^2$$.

For the case m=0, $$det(p^{\dot\alpha\alpha})=0\implies\text{rank }1$$.

Then, we can write $$\boxed{p^{\dot\alpha\alpha}=\lambda^\alpha\tilde\lambda^{\dot\alpha}}$$, i.e., the bispinor form.

If p is real, $$\tilde\lambda=\pm\lambda^*$$

If p is complex, $$\lambda$$ and $$\tilde\lambda$$ are independent.

Now, $$p^{\dot\alpha\alpha}$$ is invariant under $$\begin{cases}\lambda\rightarrow e^{-i\phi}\lambda\\\tilde\lambda\rightarrow e^{i\phi}\tilde\lambda\end{cases}$$.
